# SnippedCodes

A simple code snippet management website built with React and Vite.

## Features

- Create new code snippets
- View saved snippets
- Edit existing snippets
- Delete snippets
- Filter snippets by programming language
- Save snippets in the browser

## Technologies

- React
- Vite
- JavaScript
- CSS
- LocalStorage

## Installation and Setup

1. Download or clone this repository.
2. Open the project folder in your terminal.
3. Install the dependencies:

   ```
   npm install
   ```

4. Start the development server:

   ```
   npm run dev
   ```

5. The website will be available at:

   http://localhost:5173

## Data Storage

Snippets are stored in the browser using LocalStorage.

Data remains saved after refreshing the page or restarting the server. Clearing browser site data removes the saved snippets.
